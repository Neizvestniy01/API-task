## -----Інструкція для користувача-----

1. Запустити Python код прописавши cd "шлях" та команду python practic.py (наприклад в PyCharm).
2. Відкрити Postman і в залежності від потрібної операції скопіювати посилання з документації (або взяти частину посилання з консолі після запуску Python коду і назву потрібного API).
3. Якщо GET: просто скопіювати посилання.  
   Якщо DELETE: в кінці посиланням можна змінити цифру (id) користувача.  
   Якщо POST: окрім посилання, в Body -> raw -> Json треба написати дані про нового користувача (ім'я та електронну пошту).  
   Якщо PATCH: в кінці посиланням можна змінити цифру (id) користувача, і також, в Body -> raw -> Json треба написати нові дані.
