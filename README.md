## -----Інструкція для користувача-----

0. Завантажити бібліотеки flask, PyJWT.  
1. Запустити Python код прописавши cd "шлях" та команду python practic.py (наприклад в PyCharm).  
2. В коді в users можна переглянути, хто адмін, а хто звичайний користувач.  
3. Відкрити Postman і скористатись Login_Users, щоб отримати токен (Login_Users: скопіювати посилання, в Body -> raw -> Json треба написати дані користувача.  ).  
4. Якщо користувач - адміністратор, йому будуть доступні всі функції нижче, якщо ж користувач - то нічого не буде доступно.  
5. Операції:  
   Get_Users: просто скопіювати посилання.  
   Delete_Users: в кінці посиланням можна змінити цифру (id) користувача.  
   Post_Users: окрім посилання, в Body -> raw -> Json треба написати дані про нового користувача (ім'я та електронну пошту).  
   Patch_Users: в кінці посиланням можна змінити цифру (id) користувача, і також, в Body -> raw -> Json треба написати нові дані.
